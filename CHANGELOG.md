# Changelog

## v1.2.1

### 🔐 Root

- Помимо Magisk добавлена поддержка KernelSU.
- Добавлена кнопка проверки root-доступа в разделе «Об устройстве».
- Улучшена работа привилегированных функций без ADB.

## v1.2.0

Крупное обновление интерфейса, навигации, установки APK и системы обновлений.

### 🔄 OTA-обновления

- Добавлено самостоятельное обновление приложения через GitHub Releases.
- На главном экране появляется уведомление о доступной версии.
- Добавлен отдельный экран с описанием релиза, журналом и прогрессом загрузки.
- Перед установкой проверяются SHA-256, имя пакета, версия и сертификат подписи.
- При наличии ADB/root обновление устанавливается без подтверждения.
- Если привилегии недоступны, автоматически открывается штатный установщик Android.

### 📦 Установка APK

- APK можно передать с телефона через QR-код и локальную веб-страницу.
- Поддерживаются загрузка файла и установка по прямой ссылке.
- Добавлен подробный журнал передачи, проверки и установки.
- QR-карточка стала компактнее, а журнал получил больше места.
- Добавлена анимация текущего этапа установки.
- Сначала используются способы тихой установки, затем системный установщик.

### 🎨 Интерфейс

- Приложение переименовано в **YaOS A11y Manager**.
- Все разделы приведены к единой сетке: одинаковые поля, заголовки, карточки и кнопки.
- Добавлены плавные изменения цвета, окантовка и лёгкое увеличение сфокусированных карточек.
- Активный этап OTA плавно переливается от неактивного цвета к зелёному.
- Прогресс загрузки показывает процент, объём и скорость.
- Длинные названия и имена пакетов прокручиваются при фокусе.
- Номер версии отображается рядом с названием приложения.

### 🎮 Навигация

- Переработано управление списками приложений и системных пресетов.
- Кнопка `Влево` возвращает фокус из списка к действиям.
- При возвращении в список сохраняется ранее выбранная строка.
- Улучшено переключение между accessibility-службой и кнопкой её защиты.
- Исправлена навигация между описанием релиза, журналом и кнопками OTA.
- Перезапуск QR-сервера больше не сбрасывает фокус.

### 🔧 Исправления

- Исправлена недоступность общей очистки кэша при управлении с пульта.
- Исправлен сброс списка приложений в начало после возвращения фокуса.
- Устранено переполнение экрана «Об устройстве».
- Исправлено обрезание статуса под QR-кодом.
- Исправлено восстановление фокуса после обновления списков.
- Улучшено управление защитой выбранных служб специальных возможностей.
